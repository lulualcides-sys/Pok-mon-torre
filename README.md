# Pokémon Torre — jogo web

Esta é a versão V35.79 do Pokémon Torre. O endereço, quando o GitHub Pages estiver ativo, será **https://lulualcides-sys.github.io/Pok-mon-torre/**.

O conteúdo original foi preservado em 25 partes para evitar o limite de tamanho por arquivo e permitir atualização por GitHub.

A publicação é feita pelo workflow em `.github/workflows/deploy.yml`. Em repositórios novos talvez seja necessário habilitar o GitHub Pages em **Settings → Pages → Source: GitHub Actions** para o primeiro deploy.

⚠️ Salvamentos ficam no navegador e origem do site. No jogo, o botão **Salvar/Migrar** permite exportar e importar quando o salvamento estiver acessível ao navegador.
