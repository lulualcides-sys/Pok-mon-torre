A folha GBA recortada usada anteriormente já está neste repositório em [gba-assets](../../effects/moves/gba-assets/).

## Fluxo obrigatório para golpes futuros

- Consultar primeiro os arquivos indexados e os sprites originais fornecidos, antes de criar um efeito.
- Reproduzir o ataque fielmente, com animação dos sprites existentes e proporções compatíveis com a arena; usar pixel art sem suavização.
- Não desenhar efeitos geométricos genéricos nem esticar imagens até cobrir a tela.
- Preservar golpes já aprovados, principalmente Tri Attack.
- Manter os originais sem alterações e registrar fonte/crédito quando informado.
- O usuário informou que o jogo é **pessoal/offline**, sem intenção comercial.

**Direitos autorais:** algumas referências trazem marcas d'água comerciais (Dreamstime, Shutterstock). Elas ficam **apenas no acervo privado como referência**; não publicar esses materiais como assets de jogo sem a licença adequada. A folha original de Ruby/Sapphire informa crédito a Neslug; outras têm créditos próprios na imagem.
